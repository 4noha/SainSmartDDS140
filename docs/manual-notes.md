# マニュアル要点（実装に効くところ）

出典: `docs/manual/` の 2 冊（秋月電子 g110159 で公開、原本はベンダ CD 同梱）。
ページ番号は PDF のもの。ここは**要約**なので、判断に迷ったら原本を見ること。

## 仕様（ハードウェアマニュアル §5）

| 項目 | DDS-120 | **DDS-140** |
|---|---|---|
| 最大サンプルレート | 50 Msps | **200 Msps（1ch）/ 100 Msps（2ch）** |
| 分解能 | 8 bit | 8 bit |
| 電圧レンジ | ±5V（x10 プローブで ±50V、x100 で ±500V） | 同左 |
| 入力インピーダンス | 1MΩ / 25pF | 同左 |
| メモリ深度 | — | **64 KB** |
| トリガ | Auto / Normal / Single / None / Scan | 同左 |
| 内蔵信号 | 1 Hz・3.25V 標準矩形波 | 同左 |

**レンジごとのノイズ**（無入力時の目安。実装の判定に使える）:

| V/div | ノイズ |
|---|---|
| 1V | ±50 mV |
| 500mV | ±25 mV |
| 200mV | ±10 mV |
| 100mV | ±8 mV |
| 50mV | ±4 mV |

→ `python3 -m dds140 input-check` の数値がこれを大きく超えていたら、
何かが入力に乗っている（配線・ハム・ドリフト）と判断できる。

## プローブ（ソフトウェアマニュアル「Horizontal Toolbar」）

- ソフト側の設定は **1x / 10x / 100x**。物理プローブは 1x/10x 切替式。
- 1x で ±5V、10x で ±50V、100x で ±500V が定格。
- 設定は**ソフトの倍率**（表示電圧の換算）に効く。ハードの減衰は自動ではない。

## トリガ

- チャネル: CH1 / CH2
- エッジ: Rising / Falling
- 種類: No Trigger / Normal / Single / Auto
- Normal/Single では波形表示エリアに **T マーカー**が出て、ドラッグでレベル調整。

## Record / Review（ベンダソフトの記録機能）

- 記録は `.dds120` / `.dds140` という独自形式でアプリのフォルダに保存。
- ファイル名は `年月日時分`。
- Configuration ボタンで**記録するフレーム数**を指定。
- 記録されるのは波形だけでなく **Time ノブ・Voltage ノブの値・チャネルの ON/OFF**。
  再生時に自動で復元される。

→ 本プロジェクトの `dds140 record` はこれの代替。独自形式ではなく
`.bin`（生バイト）+ `.json`（設定・キャリブレーション）+ 任意で `.csv` にした。

## モジュール（DDS-140 のみ）

- 背面の外部モジュール端子に **信号発生器** と **ロジックアナライザ** を接続。
- ソフトの Modules で
  `Oscilloscope` / `Oscilloscope + Signal Generator` / `Logic Analyzer` を選ぶ。
- マニュアルには「電源を切った状態で着脱するのが望ましい」とある。
- 信号発生器は 1Hz〜20MHz（正弦）、PWM 出力あり。詳細は §6。

## 自動測定

最大値・最小値・周波数・立ち上がり時間・周期・デューティ・Vpp・Vrms・Vavg・DC 電圧。
カーソル（マーカー）による垂直・水平の精密測定。

## 実装との対応メモ

| マニュアルの記述 | 本実装 |
|---|---|
| 200 MS/s（1ch）/ 100 MS/s（2ch） | `cmd 148` の下位ニブル。合成モード（1ch 200MS/s）は未検証 |
| 64 KB メモリ深度 | 1 フレームの上限は実測 40 MB まで（`docs/recording.md`）。64 KB は FPGA 側バッファで、USB へはストリーム |
| レンジ別ノイズ | `input-check` の判定基準に使用 |
| 1x/10x/100x | `Frame.probe_ch1/ch2` に倍率を持たせている（UI 未露出） |
| Record/Review | `dds140 record` と UI の REC |
| 1Hz 3.25V 矩形波（内蔵） | 未使用。プローブ校正用の出力と思われる |
