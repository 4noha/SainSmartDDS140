# ハードウェア

出典: sigrok wiki（`SainSmart_DDS140` / `/Info`）。**手元の実機では未確認**。

## 構成

| 役割 | 部品 |
|---|---|
| USB | Cypress **CY7C68013A-100AXC**（FX2LP）＋ 24MHz 水晶 |
| ファーム | Microchip **24LC64I**（64Kbit I²C EEPROM。ここから起動） |
| ADC | MXTronix **MXT2088** デュアル 8bit、100MSPS |
| ロジック | Altera **EPM240T100CN**（MAX II CPLD）＋ 80MHz 水晶 |
| メモリ | ISSI **IS61LV6416-8TI**（64K×16、8ns） |
| アナログ | CD4052BM ×5（mux）、LM393（コンパレータ） |
| 電源 | AMS1117-3.3 |
| 信号発生器 | CD4052B、**AD603AR**（90MHz VGA）、AD826 |
| ロジックアナライザ | LVC4245A（レベル変換） |

## 定格（公式ページより）

- 2ch、40MHz、200MS/s（1ch）/ 100MS/s（2ch）、8bit、64K/チャンネル
- 入力: 1MΩ // 25pF、AC/DC/GND、**1x プローブで ±5V**（10x で ±50V）
- 出力（信号発生器）: ±4V、正弦 1Hz〜20MHz、PWM 200Hz〜20kHz
- 電源: USB バスパワー（MaxPower 500mA）
- 本体 130×88×28mm

## USB

| 状態 | VID:PID | 識別 |
|---|---|---|
| 通常（J1 あり） | `8312:8312` | BUUDAI / **USB104** |
| ファーム未ロード（J1 なし） | `04b4:8613` | Cypress FX2 既定 |

通常状態: interface 1 個（vendor specific）、EP 4 本。

| EP | 方向 | 転送 | サイズ |
|---|---|---|---|
| `0x82` | IN | Interrupt | 1024 |
| `0x04` | OUT | Bulk | 512 |
| `0x86` | IN | Bulk | 512 |
| `0x88` | IN | Bulk | 512 |

## 実機で確認すること

- [ ] 筐体の型番・リビジョン、`USB104` のシルク
- [ ] J1 の有無と位置（**外さない**。確認だけ）
- [ ] `8312:8312` で見えるか、descriptor が上の表と一致するか
- [ ] 信号発生器モジュールの有無（基板と BNC）
- [ ] 入力の減衰設定（1x/10x）と、繋ぐ前のレンジ

## 壊さないための注意

- 入力に ±5V を超える電圧を入れない（1x 時）。プローブの減衰を必ず確認。
- EEPROM の書き込み・消去をしない（ファームの再入手は公式 RAR のみ）。
- J1 を外したまま電源を入れ続けない（ブートローダのまま何も動かない）。
